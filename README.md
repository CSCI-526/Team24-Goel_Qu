# Ball Game

A 2D game where you draw lines to guide a ball through an exit.

## Run

1. Open the project with Unity **6000.4.10f1**.
2. Open `Assets/BallGame/Scenes/Ball Game 2D.unity`.
3. Press **Play**.

## Controls

- **Click and drag:** Draw a line to deflect the ball.
- **R:** Restart the current level.
- **Esc:** Open the pause and level selection menu.
